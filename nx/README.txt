1. Создайте репозиторий на github.com и загрузите в него ВСЁ содержимое этой папки (включая .github).
2. Вкладка Actions -> Build APK -> Run workflow (или просто после push).
3. Через ~3-5 минут откройте завершённый запуск -> Artifacts -> NextendoOnline-apk -> скачайте app-debug.apk.
4. Установите на телефон (разрешите установку из неизвестных источников).
